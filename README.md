# Privacy-Centric Hospital Management Dashboard

A privacy-first digital hospital management dashboard built with Python, Streamlit, and SQLite/MySQL. Designed to transition community hospitals from paper-based records to a GDPR-compliant digital workflow, the system enforces the CIA Triad:

- **Confidentiality:** Protects patient identities and medical records through encryption and data masking/anonymization.
- **Integrity:** Enforces Role-Based Access Control (RBAC) so only authorized personnel can modify records, backed by immutable audit logs tracking who accessed what data and why.
- **Availability:** Ensures reliable, structured record retrieval for authorized hospital staff.
